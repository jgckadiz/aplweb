Sobre Nosotros y las Galerías de Imágenes

En el módulo de Aplicaciones Web de 2º SMR, aprender a estructurar y presentar elementos multimedia como imágenes es fundamental para ofrecer una buena experiencia de usuario (UX).

Una galería de imágenes permite organizar recursos visuales mediante etiquetas semánticas como <figure> e <img>, utilizando reglas CSS (como Flexbox o Grid) para disponer las imágenes de forma adaptativa (*responsive*).
